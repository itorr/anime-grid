# 🤖「アニメ遍歴 個人的ベスト表ジェネレーター」

自分のアニメ遍歴や好みを1枚の表にまとめられるオンラインツールです。

通常版に加えて、項目数を増やした[拡張版](https://lab.magiconch.com/anime-grid/ja/ex.html)もあります。

## URL

https://lab.magiconch.com/anime-grid/ja/

## GitHub

https://github.com/itorr/anime-grid

## 利用について

- アニメ情報は [Bangumi 番组计划](https://bangumi.tv/) から取得しています。
- 商用・営利目的での利用は禁止されています。
